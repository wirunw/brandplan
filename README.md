# Brand Plan Builder

เครื่องมือช่วยเภสัชกรการตลาดทำ brand plan ทีละขั้น จากข้อมูลผลิตภัณฑ์เท่าที่มีในมือ จนได้สไลด์ 16 หน้าสำหรับนำเสนอของบ และตารางแผนกิจกรรมที่นำไปติดตามงานต่อได้

เปิดใช้งาน: https://wirunw.github.io/brandplan/

## ขั้นตอน

0. เริ่มต้น – ชื่อผลิตภัณฑ์ ประเภท (ยา Rx, ยา OTC, เครื่องมือแพทย์, ผลิตภัณฑ์เสริมอาหาร, ผลิตภัณฑ์สมุนไพร, เครื่องสำอาง) ปีของแผน และข้อมูลดิบ
1. Product concept
2. วิเคราะห์สถานการณ์ (ตลาด คู่แข่ง insight SWOT ประเด็นสำคัญ)
3. กลยุทธ์ (กลุ่มเป้าหมาย positioning เป้าหมาย กลยุทธ์หลัก)
4. ข้อความหลักและ compliance
5. ส่วนประสมการตลาดและแผนกิจกรรม
6. ประมาณการยอดขาย งบ และ ROI
7. ตัวชี้วัด ความเสี่ยง และสิ่งที่ขออนุมัติ

แต่ละขั้นมี prompt แบบ R-T-F-C ที่ใส่ข้อมูลจากขั้นก่อนหน้าไว้ให้ เมื่อวางคำตอบของ AI กลับมา กดปุ่มเดียวเพื่อนำข้อความไปใส่ช่องสรุป แล้วแก้ต่อเองได้

## สิ่งที่ส่งออกได้

- PowerPoint (แก้ข้อความได้ กราฟเป็นกราฟจริง) และ PDF
- แผนกิจกรรม .csv สำหรับ Excel หรือ Google Sheets
- ไฟล์แผน .json สำหรับทำต่อที่เครื่องอื่นหรือส่งให้ทีม

## ข้อควรรู้

- ข้อมูลเก็บในเบราว์เซอร์ของผู้ใช้เท่านั้น หน้าเว็บไม่ส่งข้อมูลไปที่ใด
- สรุปกฎระเบียบในหน้าเว็บมีไว้เพื่อการวางแผน ไม่ใช่คำแนะนำทางกฎหมาย ให้ยืนยันกับฝ่าย Regulatory Affairs และประกาศ อย. ฉบับล่าสุด
- แบบจำลองการเงินเป็นแบบอย่างง่าย ควรให้ฝ่ายการเงินตรวจก่อนนำเสนอ
- Glucoxa ในตัวอย่างเป็นยาสมมติ ตัวเลขทั้งหมดสมมติขึ้น

ไฟล์: `index.html` (หน้าเว็บและ CSS), `assets/content.js` (เนื้อหา 7 ขั้น ประเภทผลิตภัณฑ์ ตัวอย่าง), `assets/app.js` (การทำงานทั้งหมด) ไม่มีขั้นตอน build
